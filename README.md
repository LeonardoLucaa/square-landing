# Square: landing page

Landing page de uma marca de terapias naturais. Desenhei no Figma (desktop e mobile) e implementei em HTML, CSS e JavaScript.

**Design:** (https://www.figma.com/design/sLSpLnOk59u4lN4PCjI31Z/Landing-Page?node-id=0-1&t=VnNxQmHotB04Bp9t-1)

Tem menu com rolagem suave (e menu retrátil no celular) e um formulário de reserva com validação e janela de confirmação. A reserva é simulada: nenhum dado é enviado.

Para rodar, abra o `index.html` no navegador.
